# Issue 28 — Contrato de vetores de probabilidades

Baseline: `5f1169127d32b8af5ab9321a8dc3d16b73fdd514` (`packaging: pin package discovery to faultree*`).

## Abordagem e mudanças

A validação agora aceita somente escalares numéricos finitos ou vetores
numéricos finitos, unidimensionais e não vazios. Valores textuais, NaN,
inf, vetores vazios e matrizes são rejeitados antes do cálculo.

Vetores de mesmo tamanho são tratados como amostras conjuntas: `--shuffle`
aplica uma única permutação compartilhada e conserva o pareamento entre
eventos. Tamanhos diferentes passam a falhar por padrão. A reamostragem
bootstrap por marginal, que perde esse pareamento, só ocorre com a opção
explícita `resample_independent=True`, disponível no CLI como
`--resample-independent` e no corpo da API como `resample_independent`.

## Evidência de testes

` .venv/bin/python -m pytest `: 65 testes aprovados. Há cobertura para formas
inválidas, rejeição padrão de comprimentos desiguais, permutação conjunta e
aceitação explícita tanto no CLI quanto na API.

## Pendências e ideias

A reamostragem independente permanece uma conveniência para marginais; ela não
reconstrói dependências estatísticas. Uma interface futura de matriz de
amostras conjunta pode tornar essa proveniência ainda mais explícita.
